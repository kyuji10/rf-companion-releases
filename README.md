# RF Companion — releases

Downloads do RF Companion (medidor de DPS, boss, PvP e mercado para RF Online Next).

1. Baixe o `.zip` da versão mais recente em **Releases**.
2. Extraia para uma pasta sua (ex.: `Documentos\RFCompanion`) e abra o `RFCompanion.exe`.
3. Leia o `LEIA-ME.txt` dentro do zip.

O programa se atualiza sozinho quando sai uma versão nova.
